Commenced but not yet consolidated

No tracked instrument currently has commenced amendments missing from its compilation. This is checked on every sweep — when it is not empty, reading the compilation alone would give the wrong answer.

How to check this

Every row is falsifiable. Click a compilation ID to open it on the Federal Register and compare the compilation number and effective date.

Baseline rows make no latency claim. The first time an instrument is seen we were not watching when it was published, so no detection is claimed. Only rows after that measure anything.

Sweeps are recorded even when nothing changed, in data/sweeps.jsonl, including failures. A log that records only hits cannot tell you the difference between "nothing changed" and "we stopped looking", which would make any completeness claim unfalsifiable.

The log is hash-chained and append-only. Each entry commits to the previous one, so silently backfilling a missed amendment breaks the chain. Run python scripts/poll_amendments.py --verify to check it, and read the git history — commit timestamps come from the CI runner, not from us.
